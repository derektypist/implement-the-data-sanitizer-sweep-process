# Implement the Data Sanitizer Sweep Process

Clean semi-structured log files by replacing disallowed characters with # and tracking how many entries were processed.

## Technologies

Uses JavaScript and Loops.

## Deployment

Copy `script.js` into the terminal of your choice.  If using terminal, use the command `node script.js` to run the code.
